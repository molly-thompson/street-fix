# Base Repository Template

A stack-agnostic project foundation focused on developer experience (DX), clean engineering conventions, and lightweight automation.

## 🛠️ Included Governance & Conventions

- **Conventions:** Strict adherence to [Conventional Commits](https://www.conventionalcommits.org/) and a hybrid merge strategy.
- **Issue & PR Templates:** Standardized Markdown templates for Features (`feat`), Bug Reports (`fix`), and Chores/Tasks (`chore`), complete with a Definition of Done (DoD).
- **Automated Labeling:** GitHub Actions workflow to keep repository labels synchronized via `.github/labels.yml`.
- **Dependency Maintenance:** Automated weekly security and dependency monitoring via Dependabot (covering GitHub Actions, `uv`, and `npm`).

## 🚀 Getting Started

To use this template for a new project:

1. Click **"Use this template"** at the top right of this repository on GitHub.
2. Clone your new repository locally.
3. Review `CONVENTIONS.md` for branch naming, commit guidelines, and workflow standards.
4. Begin building!
